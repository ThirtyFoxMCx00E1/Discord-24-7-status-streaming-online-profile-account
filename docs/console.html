Viewing works without any setup. To use Start, Restart and Stop here, create a GitHub access token and paste it below. Without one, those buttons open the matching GitHub page instead.

  • GitHub > Settings > Developer settings > Fine-grained tokens > Generate new token.
  • Repository access: only this repository. Permissions: Actions (read and write), Variables (read and write). Expiry: 30 days.

This is a GitHub token, not your Discord token. Never paste your Discord token here or anywhere in a web page.
